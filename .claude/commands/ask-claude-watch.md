---
description: Watch a Refraction site's Ask Claude queue and build each request (Claude Code mode)
---

Build the pages people queue in Refraction's Ask Claude panel ("Claude Code" mode). This session's Claude plan does the work; the site never calls Claude. Full description: `docs/refraction/ask-claude.md`, section "Claude Code".

1. Check `REFRACTION_REST_URL` is set (and `REFRACTION_REST_USER` / `REFRACTION_REST_PASSWORD`, unless a proxy adds the credential). Run `node scripts/claude/ask-claude-queue.mjs list` once; on 401/403 tell the person the account or Application Password is wrong and stop.
2. Start a Monitor on `node scripts/claude/ask-claude-queue.mjs watch` (it runs 29 minutes, inside the Monitor's 30-minute limit; re-arm it when it ends, for as long as the person wants). It prints one JSON line per newly waiting request: `{"id", "mode", "title", "post_id"}`. While it runs, the panel shows "Claude Code is watching".
3. For every announced request, without asking:
   - `node scripts/claude/ask-claude-queue.mjs start <id>` (the panel shows "Claude is building").
   - `node scripts/claude/ask-claude-queue.mjs brief <id>` and read the whole brief file it names. It holds the person's request, the page or selected element, the widget catalog, every allowed setting, the library images, the site styles, the design guide (DESIGN DIRECTION, SIGNATURE FEATURES, SECTION RECIPES, REVIEW BEFORE ANSWERING) and the answer format.
   - **Study before designing.** Read the request twice. If it names a website, a reference or a business, look at it (WebFetch, or Playwright screenshots) for real facts, tone and existing brand colors. Look at the library images and the current page. Then write down, before any JSON: the page's idea and mood in one sentence; the palette (ink, paper, accent, tint); the type scale; the list of sections with the job of each; and the one signature moment, chosen from SIGNATURE FEATURES for this subject (not the same one every time).
   - **Build** the answer as the brief says: real copy (no invented facts; bracketed placeholders), only the listed widgets, settings and option values, `_mobile` copies for every row, library image ids only. Start sections from the recipes where they fit, restyled for this page. Write `{"elements": [...], "summary": "..."}` to a scratch file.
   - **Look at it and improve it, at least twice.** `node scripts/claude/ask-claude-queue.mjs preview <id> --file <file> --shots <scratch dir>` saves the answer into a hidden draft copy of the page (the person's page is not touched) and saves `desktop.png` and `phone.png`. Fix every "settings left out" it prints. Open both screenshots and review them against REVIEW BEFORE ANSWERING as a demanding art director would: hierarchy at a glance, spacing rhythm, contrast over pictures, text wrapping on the phone, overflow, anything that looks like a template. Change the file and preview again; repeat until nothing on the list fails (two rounds at least).
   - `node scripts/claude/ask-claude-queue.mjs result <id> --file <file>` (it also deletes the preview draft). If it is refused (invalid JSON, nothing usable, or not exactly one element for a "Change selected" request), fix the file and send it again.
   - If the request cannot be built with Refraction's widgets (or should not be built), `node scripts/claude/ask-claude-queue.mjs decline <id> --note "why, and what to ask instead"`.
4. The person inserts the result from the panel. Report what you built for each request: the idea in one sentence, the signature moment, the placeholders to fill, and the final desktop and phone screenshots (send them to the person).
