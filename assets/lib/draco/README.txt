Draco glTF decoder (WebAssembly build), copied unchanged from three.js r172
(examples/jsm/libs/draco/gltf/). Draco is Apache-2.0, https://github.com/google/draco.

The 3D Model widget points <model-viewer> at this folder so Draco-compressed
.glb files exported from Blender decode without contacting gstatic.com.
