# SafeKab artwork

Put the brand artwork here as PNG files with a transparent background. A file that is present
replaces that decal's placeholder on the next build; a missing file keeps the placeholder.

| File | Used for | Decal size (w × h) |
|------|----------|--------------------|
| `stripe.png` | Blue band with teal edge along both sides | 1.95 × 0.36 m |
| `wordmark.png` | "SafeKab" on the side band | 0.95 × 0.20 m |
| `roundel.png` | "Pre-booked iT" sticker on the rear wings | 0.34 × 0.34 m |
| `logo.png` | S logo and wordmark on the bonnet | 0.62 × 0.62 m |
| `plate_front.png` | Front plate ("SAFETY FIRST") | 0.52 × 0.11 m |
| `plate_rear.png` | Rear plate | 0.52 × 0.11 m |

Match the decal's aspect ratio, or the image is stretched to fit. Sizes and positions are set in
`../livery.py` (`DECALS`).
