Refraction is a drag-and-drop page builder for WordPress that works fully offline.

== Description ==

Refraction is a drag-and-drop page builder for WordPress, forked from the open-source Elementor plugin and developed independently. It makes no calls to external accounts, libraries or telemetry services.

Refraction is not affiliated with or endorsed by Elementor Ltd.
