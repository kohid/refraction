A plain theme for sites built with the Refraction page builder.

== Description ==

Just Refraction gets out of the way. It has no design of its own, loads no fonts or scripts, and never adds styles to a page built with Refraction, so what you design is what visitors see.

* Refraction's Theme Builder supplies the header, footer, single, archive, search and 404 templates. The theme prints them itself (it declares Refraction Theme Builder support), so nothing is printed twice.
* Where Refraction has no header or footer for a page, the theme shows a simple one: your logo or site name, the Header menu and the Footer menu. Turn it off in Appearance > Customize > Just Refraction.
* Posts and pages not built with Refraction get a minimal reading style (a readable width and spacing). Turn it off in the same place for a completely unstyled theme.
* Accessible basics: a skip link to the content, landmarks, and WordPress's screen-reader text class.
