# Rename leftovers (stage 1)

The rename was done by `scripts/rename-to-refraction.mjs` (deterministic and re-runnable; a second run changes nothing).
First run: 3,977 files changed, 380 files/directories renamed, 596 `ELEMENTOR` + 6,636 `Elementor` + 31,570 `elementor`
replacements, 22 "an Elementor" -> "a Refraction" grammar fixes.

Not touched on purpose (stage 1): `.git`, `node_modules`, `vendor*`, `license.txt`, `NOTICE`, `changelog.txt`, `readme.txt` (hand
written), `composer.lock` (regenerated by composer), every `*.md`, and `docs/`. Binary files are not rewritten.
Stage 2 also rewrites `docs/**` (except `docs/refraction/`) and nested Markdown, and leaves root-level Markdown, `CHANGELOG.md` files
and recorded test fixtures alone.

## Not renamed because it is not practical

Stage 2 (see [branding-status.md](branding-status.md)) resolved the former entries here: the icon font is now `rficons` with an
original prism glyph, the onboarding logo components draw the Refraction mark, and the upstream service URLs and remote
images are gone. What is left of the old name, with reasons, is listed in `branding-status.md`.

* **Third-party/tests binaries**: screenshot snapshots and playwright resources (`tests/playwright/resources/refraction1-4.png`
  were renamed but still show the old artwork). Test fixtures only; not shipped.

## Replaced brand assets

`assets/images/logo-panel.svg`, `assets/images/logo-platform.svg`, `assets/images/logo-icon.png` and

## Manual follow-ups applied after the script

* `refraction.php` header written by hand: version 0.1.0, `Author: Refraction contributors (based on Elementor by Elementor.com)`,
  GPL-3.0-or-later, `Text Domain: refraction`.
* `package.json` / `packages/**/package.json`: `homepage`, `repository.url` and `bugs.url` now point at `github.com/kohid/refraction`;
  root version 0.1.0 (workspace package versions stay at 4.4.0).
* `package-lock.json` was rewritten by the same script; the `@elementor-external/angie-sdk` alias was restored by hand.
* `scripts/vite/shared/packages-externals.mjs` and `externals.mjs`: the regexes for `@elementor/(ui|icons)` deep imports were
  restored (they use an escaped slash the script's package protection cannot see); the "all packages" regex accepts both scopes.
* `composer.json`: name `refraction/refraction`, license, authors, description.
* `composer.lock` is stale (still lists upstream packages) and is regenerated in stage 2.
